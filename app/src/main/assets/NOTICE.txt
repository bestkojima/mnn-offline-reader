Examples: authored for this project, 12 words / 24 bilingual examples.
The first build does not provide example coverage for every dictionary entry.
Inference and preprocessing were checked against the publisher's model contract
and the community reference at https://github.com/vra/supertonic-mnn .

Language identification: Google ML Kit bundled language-id 17.0.6.
Model is packaged locally; no Play Services model download.
SDK terms and privacy: https://developers.google.com/ml-kit/terms
API documentation: https://developers.google.com/ml-kit/language/identification/android
The application uses INTERNET and ACCESS_NETWORK_STATE for explicitly started ModelScope downloads.
Language detection and speech inference run on device; selected text is not sent in model requests.

Mandarin TTS: Kokoro-82M v1.0 (Apache-2.0).
Original model: https://huggingface.co/hexgrad/Kokoro-82M
MNN conversion: wangjazz/kokoro-82m-mnn, c161c9db569b944c35e06f5c3042e4c575aee4a9.
Phoneme lexicons: csukuangfj/kokoro-multi-lang-v1_0, f7b96bb6bef5c5da4d3aa4f4e0498fbbf62dc78b.
Voice data: onnx-community/Kokoro-82M-v1.0-ONNX, 1939ad2a8e416c0acfeecc08a694d14ef25f2231.
Selected voices: zf_xiaoxiao, zm_yunxi. No other Kokoro voices are packaged.
Full Apache-2.0 notices are packaged at licenses/KOKORO-LICENSE.
The application implements lexicon-based Chinese preprocessing; it does not embed the sherpa-onnx runtime or eSpeak.
